We built TRACE//GOA — an agentic fraud investigation engine powered by @TigerGraphDB for Hacker House Goa 2026.

Give it a fraud alert. It traverses the transaction graph, finds shared devices and billing region anomalies, retrieves similar past investigations as memory, and produces a policy-compliant recommendation — before and after requesting evidence.

590,742 real IEEE-CIS transactions. 5,565 historical cases as agent memory. 20 live benchmark cases. Two undocumented fraud patterns discovered from the data.

Built on:
• TigerGraph GSQL (7 installed queries)
• Official TigerGraph MCP server
• GraphRAG: subgraph + policy docs + case memory
• SHA-256 hash-chained audit ledger
• FastAPI + React 19
